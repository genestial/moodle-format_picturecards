# Changelog

## 1.0.0

- Build `2026110900`: move exact horizontal and vertical crop-focus fields directly beneath the image preview and explain the percentage directions.

- Release build `2026110601`: label icon-picker listboxes for screen readers, keep Tile appearance clickable above the activity link, clean activity media rows when course contents are deleted after a format switch, enforce a positive plugin image cap for users who can ignore Moodle file limits, and clarify image retention help.

- First stable PictureCards release, maintained by GENESTIAL (admin@genestial.com, https://www.genestial.com).
- Show a course banner, topic cards, and activity cards. Topics use an uploaded picture or one of sixteen built-in icons. Activities use Moodle's icon, a built-in icon, or an uploaded image.
- Keep a saved picture when a topic or activity switches to another media type, until the file is removed and the form is saved.
- Provide site and course colour palettes, tiles and list layouts, backup and restore, and Privacy API export and deletion for uploaded images.
- Let courses hide an empty General section and choose between the PictureCards banner and the theme's normal course header.
- Support Moodle 4.5 through 5.3. Moodle 5.0 no longer receives security updates.
- Free plugin. No paid tier, external account, or administrator build step. Moodle App support is not claimed.
