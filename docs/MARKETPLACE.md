## Summary

A topic-based course format with a course banner, picture tiles for topics and visual activity cards.

## Description

The course overview shows a banner using the course title and course image, with an optional course description. The General section displays its summary and compact activity links. Teachers can choose one picture for each topic from a Topic appearance control in edit mode. Tiles view shows topics as cards with grouped activity counts; selecting a card opens its activities. List view shows full sections. Topic labels can be hidden or renamed, and site and course settings offer colour palettes with a live preview. Activity cards can use Moodle's icons, one of eight built-in symbols, or an uploaded JPG, PNG, GIF or WebP. Tiles and lists use Moodle's course index, activity names and access restrictions.

Administrators can cap image size. Media stays in Moodle without external accounts/services. Backup/restore and Privacy API support cover topic and activity images and uploader metadata. Original format; unaffiliated with Tiles.

## Compatibility and privacy

Target Moodle 4.5 through 5.3; compatibility work and verification are in progress. Publish only combinations verified in release evidence. No Moodle App support or administrator build steps are claimed.

Images and File API metadata may contain personal data. Activity images live in module contexts; topic pictures live in course contexts and are limited by section visibility. Privacy requests export/delete approved uploaders' files. Shared settings contain no user identifier. No external data transfers. See README for retention.
