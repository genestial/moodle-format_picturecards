# Security policy

Please do not report suspected security vulnerabilities in public issues.
Report them privately using [GitHub's vulnerability reporting](https://github.com/genestial/moodle-format_picturecards/security/advisories/new).
Include the affected plugin and Moodle versions and enough detail to reproduce the issue. The maintainer will coordinate a fix and disclosure.

PictureCards has not yet published a stable release. Supported versions will be listed with the release.
