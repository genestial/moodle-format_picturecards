# Security policy

PictureCards is maintained by GENESTIAL (admin@genestial.com, https://www.genestial.com).

Please do not report suspected security vulnerabilities in public issues.
Report them privately using [GitHub's vulnerability reporting](https://github.com/genestial/moodle-format_picturecards/security/advisories/new).
If GitHub reporting is unavailable, email admin@genestial.com with the subject "PictureCards security report".
Include the affected plugin and Moodle versions and enough detail to reproduce the issue. GENESTIAL will coordinate a fix and disclosure.

Bugs and feature requests belong in the [public issue tracker](https://github.com/genestial/moodle-format_picturecards/issues).
